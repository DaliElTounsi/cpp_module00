# C++ Module 00 — C++ Foundations, Classes & Encapsulation

The first module of the **42 School C++ curriculum**, introducing the transition from C to object-oriented programming in C++98.

This repository contains a sequence of small exercises designed to build the foundations of class-based design, encapsulation, namespaces, streams and basic object lifecycle management.

## What this module demonstrates

- C++98 syntax and compilation
- Namespaces and standard streams
- Classes and objects
- Public and private members
- Constructors and destructors
- Member functions
- Encapsulation and data validation
- Static members and constants
- Basic command-line application design

## Exercises

### ex00 — Megaphone
A small command-line program used to become familiar with C++ streams and string manipulation.

### ex01 — PhoneBook
A console-based contact manager built with `Contact` and `PhoneBook` classes. It introduces object modeling, encapsulation, fixed-size storage and formatted console output.

### ex02 — Account
An exercise focused on class behavior, static members and tracking state shared across multiple objects.

## Why it matters

This module marks the shift from procedural C toward **object-oriented software design**. The PhoneBook exercise in particular introduces the idea that data and behavior should be grouped behind clear class interfaces rather than manipulated globally.

## Build

Each exercise contains its own `Makefile`.

```bash
cd ex01
make
```
